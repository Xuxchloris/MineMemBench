## Findings closed before PASS

1. **High — strict transfer overwrite:** a correct equip followed by a wrong
   equip before the first attack could be misreported as success. Ordered
   equipped state and an overwrite regression now enforce the actual item at
   the first attack.
2. **High — cross-campaign Compare contamination:** identical treatments in
   different campaigns were treated as duplicates. Compare is now scoped to
   the anchor campaign; standalone evidence remains conservatively global.
3. **High — invalid producer aggregation:** failed or fairness-invalid linked
   results could contribute research aggregates. Success, tokens and all
   latency aggregates now require producer `status=ok` and valid fairness.
4. **High — post-terminal actions:** new scenarios originally ran to
   `max_steps` after objective completion. A backend-neutral terminal predicate
   now stops only after recorded environment evidence proves completion.
5. **High — authored mapping shortcuts:** semantic entity names and ordinal
   family/resource order could reveal the answer. Opaque alpha/beta/gamma
   families use the non-ordinal permutation alpha→iron, beta→string,
   gamma→gold, with regression coverage.
