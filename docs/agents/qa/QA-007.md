## 2. Code findings (independent inspection)

### 2.1 Backend-neutral planner memory serializer — implemented as required

`benchmark/minemembench/agent/planner.py::memory_view_for_prompt(item)` (lines
139–163) returns exactly
`{"event": {actor, target, event_type, location, context, outcome}}` and is the
only path memories take into the prompt (`_build_user_message`, line 212:
`[memory_view_for_prompt(item) for item in memories]`).

Confirmed excluded from the prompt: `item_id`, `score`, `created_at`,
`metadata`, and event `event_id`, `episode_id`, `timestamp`, `raw_events` —
matching TASK-007 item 1. Applied identically for every backend and mode (no
backend-name branch). Verified by
`test_planner.py::test_memory_view_for_prompt_strips_all_nonsemantic_fields`
(asserts key set `{"event"}` with exactly the six semantic keys; serialized
view contains none of the banned keys nor the values `m1`/`ep-1`/`0.9`/
`2026-08-07`; semantic content intact).

### 2.2 Controlled distractor neutralization — implemented as required

`benchmark/minemembench/scenarios/delayed_recall.py::interference_phase`
(lines 338–372): when `ctx.campaign_mode == "controlled"` AND
`context["subject"] == "target_chest"`, the distractor is rewritten to
actor `scenario-instructor`, event_type `LOCATION_DISCOVERED`, context
`{subject, x, y, z}` — the learned fact's exact structure — dropping the
`wrong location` / `used to be located here` notes. Candidates differ only in
coordinates and retrieval order. `wrong_fact_ids` is still maintained
out-of-band (lines 371–372), so `fact_retrieval_rank` / `recall_accuracy` /
`wrong_fact_rate` / `retrieval_precision` remain re-derivable and never drive
actions.

Verified by `test_controlled_mode.py::test_controlled_target_candidates_are_structurally_identical`
(all 5 `target_chest` facts share actor/type/context-key-set, distinct
deterministic coords, `ctrl-` ids, no `wrong|used to be|stale|old|former|decoy|correct`).

### 2.3 Native mode preserved — verified

`test_controlled_mode.py::test_controlled_distractor_labels_survive_in_native_mode`
asserts native distractors keep actor `environment` and the notes
