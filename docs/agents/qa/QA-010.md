## 7. Anomalies / narrow supported conclusion

- Anomaly to highlight: restoring the event timestamp produced **no behavioral
  change** — the planner still follows retrieval item 1, so the "learned at
  the start" cue is not used by the unchanged LLM at this difficulty. Vector's
  success is explained by its retrieval placing the correct fact first
  (score-tie + stable oldest-first order), not by temporal reasoning.
- Narrow conclusion (3 runs/cell, diagnostic smoke only, per
  A-APPROVAL-009/010): at `(200,20)`, with neutral candidate content, semantic
  time visible, and backend internals hidden, behavior tracks retrieval item 1;
  vector is the only backend whose top-1 is the correct fact, while mem0 and
  letta fail behaviorally (and mem0 seeds 43/44 fail to retrieve the fact at
  all). No superiority or Failure-Point claim; formal experiments still need an
  immutable code revision and n > 3. Stopping for A's final research review.
