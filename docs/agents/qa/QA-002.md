## 5. stress-Letta seed-42 anomaly — evidence

Log: `results/stress_round1/scenario_delayed_recall_letta_7399ebc5617640238e1e1d369dc75855.json`

- `metrics`: `task_success=0`, `fact_retrieval_rank=1`, `recall_accuracy=1`,
  `wrong_fact_rate=0.2`, `retrieval_precision=0.3`,
  `final_distance_to_target=27.662`, `avg_add_latency_ms=286.1`,
  `avg_retrieve_latency_ms=202.3`.
- `run_log.steps[0]`: planner retrieved the correct fact at rank 1
  (`location_discovered` target_chest at x=33.5, z=240.48) yet `move_to` went to
  (60.5, 246.48) — the coordinates of a `world_fact_updated` "used to be
  located here" distractor (`wrong_fact_ids`). Reason: "The target chest was
  moved to this new location according to the latest world fact update."
- Interpretation: retrieval was correct (rank 1, recall 1); behavior failed
  because the planner followed a plausible-looking stale-location distractor.
  This is a genuine behavior-vs-retrieval divergence the stress layer is
  designed to expose — **not excluded, not a test artifact**. It is retained as
  a `success=False` log.
